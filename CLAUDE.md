## Critical Rules (Always Apply)

- **§0.1 — IMPORTANT: YOU MUST NOT commit or push unless the engineer explicitly asks.** Work is reviewed via `wd` first; branch from `master` when starting non-trivial work.
- **§0.2 — IMPORTANT: NEVER un-hide the Whisper engine.** `SHOW_WHISPER_TOGGLE` stays `false`; do NOT wire `useVoiceRecognition` / `useWhisperRecognition` into practice screens. The live recognition path is Web Speech only.
- **§0.3 — `src/lib/` is framework-free pure logic with a co-located `*.test.ts`.** Do NOT import React/DOM in `lib/`. Number generators MUST yield integer-only operands AND answers — no fractions or decimals leak (conversions cap the small side and divide evenly).
- **§0.4 — i18n parity.** Every UI string has a key in BOTH `src/i18n/locales/hr.json` and `en.json`. Word/convert lessons stay HR-only via the lesson's `languages` field — NEVER hardcode Croatian copy in components.
